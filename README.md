# Portfolio Website (HTML Starter)

A basic HTML portfolio-page starter created to practise semantic page sections and navigation.

## Current contents
- Header navigation with About, Projects, and Contact links
- Introductory, About, Projects, and Contact sections
- A simple contact-form layout

## Technologies
- HTML5

## Run locally
1. Clone this repository.
2. Open `Portfolio Website.html` in a browser.

## Known improvements needed
- The page currently contains placeholder text such as `[Your Name]` and sample project content.
- Its stylesheet and navigation links use local file paths from the original computer. Replace these with relative paths before sharing or deploying.
- Add the missing form fields and a real stylesheet.

## Status
Learning starter / work in progress. Not presented as a finished production portfolio.
